# Qualitative Figure

The final qualitative figure used in the paper is stored at:

```text
figures/qualitative/vad_agent_qualitative.jpg
```

The plotted curves use the same detection settings as the main reported VAD-Agent rows:

- UCF-Crime: stride projection, top-ratio `0.10`, temperature `10`, smoothing window `15`, sigma `10`, position weighting, and `0.1` direct-segment fusion.
- XD-Violence: stride projection, top-ratio `0.15`, temperature `10`, smoothing window `30`, sigma `30`, position weighting, and `0.1` direct-segment fusion.

Raw video frames are not included in this repository.
